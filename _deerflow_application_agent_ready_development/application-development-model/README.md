# 应用开发模型 · 独立应用仓的图解主卷

## 本卷定位

这卷面向刚创建独立 DeerFlow 应用仓的维护者和 coding agent，讲清关键概念、完整开发闭环、测试证据与交付判断。读者不需要先通读另外两卷，就能回答"从哪里开始、选哪种接入形态、怎样证明应用工作、哪些事情仍需自己决定"。

本页只说明本卷职责；概念、闭环与页面导航在[总览页](./00-index.md)。本卷综合 DeerFlow 一手机制，不新增官方方法名，也不把 DeerFlow 主仓库的贡献制度强加给应用仓。所有机制依据来自固定版本 v2.1.0 的 DeerFlow 源码、文档、指南与示例；其他研究材料不参与本卷的证据链。
